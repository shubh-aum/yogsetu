# YogSetu

Landing page for YogSetu — verified yoga teachers across India.

Static single-page site, no build step required.

## Structure

- `index.html` — the page
- `assets/images/` — photos and illustrations
- `assets/videos/` — hero and section video clips

## Running locally

Open `index.html` directly in a browser, or serve the folder with any static file server, e.g.:

```
npx serve .
```
